# GCC runtime code in the wide-number image

`wide_blob.h` includes x86-64 machine code compiled from `wide_runtime.c` and
the arithmetic/conversion helpers selected from GCC 14's `libgcc.a` by the
linker. These helpers are Copyright Free Software Foundation, Inc. and
contributors, licensed under GPL version 3 or later with the GCC Runtime
Library Exception, version 3.1. The license and exception are included here.

Upstream sources: https://gcc.gnu.org/git/?p=gcc.git;a=tree;f=libgcc;hb=releases/gcc-14
(`soft-fp/`, integer arithmetic helpers, and their support files).

The image is generated by an eligible GCC compilation of the independent C
module using `python3 scripts/build-wide-runtime.py`. It has no unresolved
symbols, writable sections, libc dependency or OS-specific entry points.
Normal QYNO builds use the checked-in image; rebuilding it requires an x86-64
Linux GCC toolchain and GNU binutils. The script checks dependencies and image
sections before writing the header. It does not copy GCC intermediate code.
