# Changelog

## 0.26.14

- int_128 / unsigned int_128 / half / quadrupleのハイライト・宣言解析・型名補完を追加。
- 変換の引数ヒントと実数のe / E指数表記に対応。
- コンパイラ診断、表示名、同梱VSIXを0.26.14へ更新。

## 0.26.13

- 表示名を QYNO 0.26.13 に変更。
- セミコロン後の改行でタブ1段を追加。文字列・コメント内のセミコロンは除外。
- 文字列内の補間を文字列スコープから分離し、括弧・式を通常のコードと同じ色で表示。
- qyc 連携の構文・型・未宣言エラーの赤線、警告、問題パネルと即時検査コマンドを追加。
- 未保存のエントリ・モジュール・新規ファイル、検査の中止・一時ファイルの削除、コンパイラ設定に対応。
- 複素数型と前置／後置iのリテラルのハイライト・解析に対応。
- 型付き変数・配列要素のreal / imag補完・ホバーと、構築関数の名前付き補完・引数ヒントを追加。
- math.sqrt / absの説明と `0.26.13_VSCode_option.vsix` を更新。

## 0.26.12

- int / unsigned intの32bit化に合わせて型変換の説明と候補を更新。
- lengthとfile.writeの戻り値をint_64、型省略のforカウンターをautoと表示。
- `0.26.12_VSCode_option.vsix` を同梱。

## 0.26.11

- int_8 / int_16 / int_32 / int_64とunsigned整数型のハイライト・名前補完に対応。
- unsignedを含む引数・戻り値・変数・forカウンターの型表示、定義参照、変換関数の引数ヒントを追加。
- `0.26.11_VSCode_option.vsix` を同梱。

## 0.26.5

- xor / bnot、シフト、4基数の整数リテラルと書式指定のハイライトに対応。
- 埋め込み式内の文字列を解析し、書式指定と式のコロンを区別。
- 書式候補0b / 0o / 0d / 0xの補完と、int / strの基数変換・名前付き引数のヒントを追加。
- `0.26.5_VSCode_option.vsix` を同梱。
